# Workspace

Operational artifacts for your professional service firm. This folder is **committed**
to git — it is your firm's workspace, not throwaway output.

## Areas

| Folder | Maister dimension | Contents |
|--------|-------------------|----------|
| `firm/` | Identity | Company profile, service definitions |
| `marketing/` | Visible expertise | ICP, content ideas, drafts, landing pages |
| `sales/` | Client development | Prospecting sequences |
| `intelligence/` | Market awareness | Competitor profiles, weekly reports |
| `pdca/` | Cross-cutting | Measurement areas, cycles, scoreboards, evals |

## Conventions

See [docs/WORKSPACE.md](../docs/WORKSPACE.md) for naming rules and skill output paths.

Before creating files, read `workspace/firm/profile.md` and the README in the target subfolder.
