# Blog Post — Format Requirements

Blog format requirements — the highest-priority layer in generation.

## Length

- **800–1500 words**
- H2 and H3 section headers
- Output: **Markdown**

## Framework selection (by buying stage)

The blog format layer offers eight frameworks: Expert Opinion Funnel,
QAB (Question-Answer-Bite), PASTOR, STARR, Value Case (BCS), Positioning
Statement, AIDA, and BAB (Before-After-Bridge). Pick the best match for the
idea's buying stage:

| Stage | Frameworks | Purpose |
|-------|-----------|---------|
| Problem | AIDA, PASTOR, BAB | Help reader name and understand the problem |
| Concept | QAB, Positioning, Value Case | Explain solution categories and approaches |
| Education | Expert Opinion, QAB, Value Case | Deep-dive how-to, methodologies, frameworks |
| Decision | STARR, PASTOR, BAB | Proof, results, risk reduction |
| Vendor | STARR, Positioning, Expert Opinion | Validation, differentiation, trust |

Pick ONE framework best matching idea buying_stage and state it in draft metadata comment.

## Structure rules

- Bold claim or data hook in opening paragraph
- Concrete examples from service/ICP context
- No "In today's world", "In conclusion", "game-changing"
- Actionable takeaways per section
- End with stage-appropriate CTA (single CTA, not scattered)

## Output format

- Clean Markdown: `##` for H2, `###` for H3
- `**bold**` for emphasis, used sparingly
- Sentence case for headings (not Title Case Each Word)
- No emoji
- Bullet lists only for 3+ related items

## Anti-patterns

- Generic listicles without angle
- Vague claims without numbers
- Summary section titled "Conclusion"
