# Case Study — Format Requirements

## Length

500–1500 words | Markdown output

## Structure

1. HEADLINE — result + timeframe
2. EXECUTIVE SUMMARY (2–3 sentences)
3. THE CHALLENGE (Problem + Amplify)
4. THE SOLUTION (approach, process)
5. THE RESULTS (Transformation — metrics, quotes, before/after)
6. NEXT STEPS (Offer + Response CTA)

## Required elements

- Minimum 2–3 quantifiable metrics
- Client quote or testimonial placeholder
- Before vs after comparison
- Specific timeline

## Restrictions

- buying_stage: decision or vendor only
- No vague "improved efficiency" — use numbers
