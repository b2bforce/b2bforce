# X Post — Format Requirements

## Length

- Optimal: **150–250 characters** per tweet
- Maximum: **280 characters** per tweet
- Threads: **8–12 tweets** for educational content

## Rules

- Native content only — **NO external links in body**
- 1–2 hashtags maximum, at end
- Short punchy sentences, line breaks for readability
- Engagement question at end to drive replies
- 0–2 emojis if brand-appropriate
- One clear idea per tweet

## Output format

Plain text. No Markdown.

Threads: separate tweets with `---` on its own line between tweets.

## Anti-patterns

- Link shorteners in main tweet
- Hashtag stuffing
- Thread longer than 12 tweets without user request
