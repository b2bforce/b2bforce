# LinkedIn Post — Format Requirements

## Length

- Optimal: **150–250 words**
- Maximum: **300 words** (~1800 chars)
- Hard platform limit: 3000 characters

## Formatting

- One sentence per line
- Short paragraphs (1–3 sentences)
- NO markdown headers (## ignored by LinkedIn)
- NO bullet lists — use short sentences instead
- 0–2 emojis max
- 2–3 relevant hashtags at end
- End with engagement question

## Voice

First person: "I", "we", "you"

## Output

Plain text only in body field. Bold (`**`) sparingly if at all.
